# Computer Science — baza wiedzy

Osobista baza wiedzy z **Computer Science, Software Engineering i AI Engineering**, prowadzona w Markdown.

W repozytorium znajdują się **notatki, mapy wiedzy, wnioski i case studies z projektów**. Nie przechowujemy tutaj kompletnych projektów ani ich kodu źródłowego — tylko wiedzę, która z nich wynika.

## Dwie strefy

- **[Inbox](Inbox/README.md)** — przestrzeń robocza asystenta: szkice, pomysły, notatki, propozycje zmian oraz robocze case studies.
- **[Notes](Notes/README.md)** — uporządkowana baza właściciela, aktualizowana przez asystenta jedynie za jego wyraźną zgodą.
