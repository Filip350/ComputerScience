# Computer Science — baza wiedzy

Repozytorium do nauki **Computer Science, Software Engineering i AI Engineering**.

## Dwie strefy

- **[Inbox](Inbox/README.md)** — przestrzeń robocza asystenta: szkice, pomysły, notatki, propozycje zmian. Materiały nie muszą być ukończone ani zatwierdzone.
- **[Notes](Notes/README.md)** — uporządkowana baza wiedzy właściciela. Asystent nie zmienia jej bez wyraźnej decyzji właściciela.

Zobacz [zasady współpracy](RULES.md). Wszystkie treści w `Inbox` są propozycjami, a nie ostatecznymi notatkami.

> Repozytorium jest publiczne: nie publikuj sekretów, tokenów ani informacji prywatnych.
